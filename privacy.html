Privacy policy

Effective September 29, 2026

Household Assistant is a private tool used only by members of the Teller household. This policy explains what data it uses and how.

What data it accesses

With each user's permission, the app reads and creates events on that user's Google Calendar. It also stores the tasks, reminders, and notes that household members send to it, along with the user's name and email address.

How the data is used

Data is used only to provide the assistant's features to the household members who use it: showing schedules, adding events, sending reminders, and answering questions about their own tasks and calendars. It is not used for advertising and is never sold.

Where the data goes

Data is stored on a server owned and operated by the household. To work, the app sends message content to the following services:

  • Telegram, which carries chat messages between users and the assistant.
  • Anthropic's Claude API, which processes messages to generate the assistant's replies.
  • Google Calendar, to read and update the user's own calendar.

No data is shared with anyone else.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Any user can revoke the app's access to their Google account at any time at myaccount.google.com/permissions. To have stored data deleted, contact the operator below.
